## Technological stack

Technological stack is broken into these seperate parts:

### Frontend

- NEXT.js in TypeScript.
- TailwindCSS.
- Shadcn/ui - premade React components.
- TanStack Query - async server-state managment and API data fetching.
- Lucide React - icons.

### Backend
- Python
- FastAPI
- Pydantic
- SQLAlchemy
- HTTPX
- SQLite
